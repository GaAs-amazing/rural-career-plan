模块二 · 核心

技术硬实力

核心专业技能层，也是最重要的模块。能力矩阵围绕四件事：3D 建模、数据采集、AI 应用、引擎可视化。

2.1

实地实景数据采集技术

知识点

  • 无人机航测基础：航测飞行规范、航线规划、重叠度设置（航向重叠、旁向重叠）
  • 乡村复杂地形（山林、古村落窄巷道）的飞行风险与避坑
  • 倾斜摄影技术原理：多镜头多角度拍摄，自动化生成村落实景模型
  • 激光雷达 LiDAR 扫描：机载 / 地面激光雷达获取点云；优势是树木遮挡下仍能获取建筑结构，可做古建毫米级扫描
  • 全景影像采集：720° 全景相机，用于 VR 漫游素材
  • 实地田野配套：实地勘测记录、建筑照片归档、村落调研影像拍摄

工具清单

  • 硬件：航测无人机、地面激光雷达、全景相机、单反相机
  • 软件：无人机地面站规划软件

学习要点：分清什么场景用航测、什么场景用激光雷达；古建保护优先用 LiDAR 获取高精度结构。

数据采集无人机LiDAR
2.2

点云处理与实景三维重建

知识点

  • 点云基础概念：点云、点云配准、点云去噪、点云精简
  • 三维重建流程：原始影像输入 → 特征匹配 → 稀疏点云 → 稠密点云 → 实景网格 Mesh → 纹理映射
  • 模型问题处理：模型漏洞、漂浮噪点、纹理错乱、建筑变形修复
  • 数据轻量化：乡村大场景数据量巨大，需要网格减面与纹理压缩，保障后续引擎运行性能

工具

  • 摄影测量：ContextCapture（CC）、Metashape（Agisoft）
  • 点云处理：CloudCompare（开源免费，必学）；网格修复：MeshLab
点云三维重建轻量化
2.3

3D 建模与参数化设计

知识点

  • 通用三维建模基础：三维坐标系、UV 展开、材质纹理基础
  • 参数化设计：Rhino + Grasshopper，面向乡村微更新与景观改造方案生成
  • 传统古建筑构件知识：榫卯、木梁雕花、马头墙等江南古建构件形态
  • 模型标准化：按规范建模，为后续导入游戏引擎做准备

工具

  • Rhino 7 / 8 + Grasshopper
  • Blender：通用建模，修复实景模型破损部位，手工精细建模

两条路线要分清：实景重建得到的是「现状模型」，人工精细化建模服务的是「方案模型」与古建构件。

建模参数化RhinoBlender
2.4

AI 辅助三维建模

知识点

  • AI 构件智能识别：识别古建门窗、梁架等构件，自动分割模型
  • AIGC 生成乡村改造方案：根据现场照片生成微更新、景观改造效果图
  • LoRA 纹理生成：生成古建筑纹理，修复破损缺失的墙面雕花
  • AI 图片测量：用手机照片测距获取建筑尺寸，降低实地测绘工作量
  • 大模型结合数字孪生：AI 智能体实现 VR 场景内语音问答、村落知识库讲解

工具

  • 图片生成：Midjourney、Stable Diffusion（LoRA 训练）
  • 三维 AI：Luma AI、3D-GS 高斯泼溅重建工具
  • 大模型 API：为数字孪生平台内置 AI 问答智能体

这是本职业的特色核心——AI 不是替代建模，而是把「重复劳动」压缩，把时间让给判断与设计。

实时引擎与可视化开发（UE5）

知识点

  • 模型导入：实景大模型导入 UE5，做坐标匹配
  • 材质、光照渲染，搭建乡村户外自然环境（植被、田地、山水）

  • 输出形式：网页端轻量化数字孪生平台 / VR 设备沉浸式场景 / 渲染视频与全景漫游包

工具

  • Unreal Engine 5
  • 配套 Web 导出插件，实现在线浏览孪生场景

2.6

数理与编程基础

知识点

  • 线性代数：三维坐标变换、矩阵运算、点云底层原理
  • Python 基础：批量处理点云、批量处理图片、调用 AI 模型 API
  • 数据格式认知：ply 点云、obj / glb 模型格式
  • 不必成为后端工程师，但要看得懂代码，能对接开发人员

学习目标：看懂三维数据逻辑，能写简单脚本批量处理，能和开发团队对齐需求——数学学院背景在这里是真正的先手。

乡土人文认知

软实力内核。很多做三维技术的人容易缺失这块——数字乡建不是单纯做三维，是服务乡村。

乡村规划与建筑基础

  • 传统村落知识：江南古民居、岭南民居等不同地域的民居形制；祠堂、戏台、牌坊的功能
  • 乡村规划基础概念：微更新、人居环境整治、村庄风貌管控
  • 传统村落保护相关规范：知道哪些建筑属于保护对象，数字化建档的优先级怎么排
古建乡村规划保护规范

  • 非遗民俗、地方历史：理解村落背后的人文故事。数字孪生不只是建房子模型，还要承载文化内容
